# Reference

The OpenNPC stickman was designed from a user-supplied reference image of a
simple black walking stick figure (circular head, thick rounded limbs, no
features). That image was provided in conversation and is **not** redistributed
here.

If you have the original reference, place it at:

    assets/reference/stickman_reference.png

Nothing in the build reads that file — it is for designers only.

`opennpc_stickman_silhouette.png` is the actual OpenNPC character, rendered by
`blender/scripts/build_stickman.py`. It is an original design: separate head,
tapered torso, capsule limbs, small forward-pointing feet and a white sticker
rim so overlapping NPCs stay readable.
